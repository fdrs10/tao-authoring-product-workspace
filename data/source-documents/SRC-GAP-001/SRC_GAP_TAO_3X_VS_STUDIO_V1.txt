This analysis provides a bidirectional, evidence-based comparison of TAO Authoring and TAO

It identifies:

Capabilities that are broadly equivalent.

Capabilities where TAO Studio has an advantage.

Areas where the products address similar needs through different approaches.

Areas where the available evidence is insufficient to make a reliable determination.

The analysis is based on the consolidated TAO Authoring feature list TAO Authoring \\- feature
list.md and TAO Studio feature list TAO Studio \\- feature list.md.

Evidence principle
The analysis takes a conservative but current-evidence-based approach to TAO Studio
capabilities.

A capability is considered present in Studio when it is supported by product/user documentation or
by a recent internal capability document that explicitly describes the capability as currently
available. Roadmap-only capabilities are not treated as shipped. Where the evidence is only an
internal capability description rather than independently verified product documentation, the
capability may be accepted but the confidence is reduced where appropriate.

Similarity between Studio's forked item/test editors and the TAO 3.x editors is considered
supporting evidence only for the established item/test editing scope; it is not used to infer content-
bank, permissions, extensibility or platform capabilities.

Not evidenced does not mean not supported. It means that the available evidence is insufficient to
confidently claim support.

Comparative statuses
Equivalent — available evidence supports substantially equivalent capability.

Broadly equivalent — the same general capability exists, but complete feature parity is not
established.

Authoring advantage — Authoring has an evidenced capability or materially stronger
implementation that is not equivalently evidenced in Studio.

Studio advantage — Studio has an evidenced capability or materially stronger implementation that
is not equivalently evidenced in Authoring.

Different approach — both products address the area, but through sufficiently different models that
treating either as simply having a gap would be misleading.

Inconclusive — available evidence is insufficient to determine the comparison reliably.

Assessment
The standard item-authoring core is the strongest area of equivalence between the products.

The standard editor overlap is stronger than the previous draft suggested. Studio now has explicit
evidence for language/writing direction, stimulus use, match-correct/mapped scoring, feedback and
style editing. The main remaining Authoring advantages in this area are full PCI extensibility, direct
source editing, richer evidenced mathematical tooling, and dedicated passage-management
capabilities.
